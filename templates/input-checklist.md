# Required context and sample-document checklist

Record each item's path, date/version, reviewed status, and whether it is authoritative or an example in `input-index.md`.

| Item | Requirement | Purpose |
| --- | --- | --- |
| Resume or detailed factual career history | Required | Employment, education, skills, dates, achievements |
| Search preferences | Required | Roles, industries, geography, exclusions, level, work arrangement |
| Supporting evidence | Required for claims not established elsewhere | Project scope, outcomes, metrics, responsibilities |
| Existing resume PDF and editable source | Strongly preferred | Learn the desired format; start from generic TeX if absent |
| Alternative role-focused resumes | Optional | Choose the best base for each job |
| Cover-letter samples and source | Optional | Learn voice and layout; create and approve a sample if absent |
| Writing samples | Optional; required only for roles requesting them | Tone and role-specific evidence; do not fabricate missing work |
| Portfolio, repository links, project reports | As relevant | Substantiate scope and confirm actual URLs |
| Recommendation letters | Optional | Attributed evidence and possible outreach attachment |
| Transcript, diploma, certifications | Only when needed | Verify education/credentials; retain privately |
| Prior jobs/history workbook | Required for subsequent runs | Duplicate exclusion; initialize empty for first run |
| Detailed jobs workbook example | Optional | Preserve user's preferred output formatting |
| Application status by job | Required for “already applied” outreach | Distinguish considered from submitted |

Do not request sensitive identity documents just to complete a template. Record unknown eligibility rather than inferring it. Role-specific writing samples and extra application questions must be flagged as additional deliverables; the standard full run creates resumes, cover letters, and optional outreach only.
