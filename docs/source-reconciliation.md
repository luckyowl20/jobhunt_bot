## Observed differences and decisions

Some later campaign resumes changed typography and shortened the original 14-bullet structure. The supplied resume_template.tex and the user's repeated density instructions take precedence for this generic starter; approved user-specific changes are still supported.

One full-run manifest broadened geography to remote roles, including uncertain location eligibility. A later batch included an operations role. These are not universal defaults. The generic procedure requires explicit scope and holds unresolved hard gates outside the accepted set instead of copying those deviations.

One workbook tailoring note requested a citizenship claim while the later response omitted it pending confirmation. Tailoring notes are guidance, never authority to override evidence. Source reviews also found conflicting project metrics and implementation-status claims; the procedure retains conflict resolution and conservative wording.

The original filenames varied (`10_job_templayte.xlsx` versus actual `10_job_template.xlsx`, and history spellings). The input index now stores resolved actual paths. Contact enrichment sometimes updated a workbook and sometimes created a copy; both are supported with an explicit mode and backup.

MiKTeX/Poppler was the local render method, while one campaign explicitly recorded Tectonic because pdflatex was unavailable. The portable helper implements the former with executable discovery rather than hardcoded user paths.

## Additions for reuse

The initialization interview, persistent context templates, explicit style approval, weighted ranking rubric, stable job mapping, generic filenames, and cross-client upload/download instructions make the process usable by another person in a fresh chat. They are documented additions rather than claims that every original chat used the same implementation.

Local review included workbook sheets/headers and row structures, all 58 TeX source files for structural comparison, PDF page/text inspection, representative rendered layouts, prompts, manifests, and QA records. Historical live-job status was not reverified because this task reconstructs the process rather than runs a campaign. Prior claims of visual QA are treated as historical records, not substituted for checks on newly generated documents.
